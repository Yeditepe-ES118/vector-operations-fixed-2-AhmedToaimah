* A flight route
#+ATTR_HTML: :width 350px
[[./vectors.png]]

The origin of the coordinate system represents the center of a plane. The plane has done three consecutive displacements shown with respect to the center of the plane: $\vec v_1$, $\vec v_2$ and $\vec v_3$. Its resulting displacement is given by $\vec v_R$.

A Python program is needed to show its final position in terms of the given three displacements. The inputs are six individual components $v_1^x$, $v_1^y$, $v_2^x$, $v_2^y$, $v_3^x$, $v_3^y$ of the displacement vectors in km. Construct three displacement vectors and sum those such that $\vec v_R$ is computed.

Also find the projection of $\vec v_R$ on $\vec u$ using $\vec v_R^u = (\vec v_R \cdot \vec u) \vec u$.

Lastly, return the $\vec v_R$ as a NumPy array and the length of $\vec v_R^u$.

Create a new function called ~total_displacement~ in ~lab6.py~ to solve this problem.

For vector definitions and other special functions use NumPy.
